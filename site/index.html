      Check your own project

      The same verification runs directly on your local lockfile for the exact versions you pin:

      uvx wheelgap -p 3.13 -t linux-aarch64,musl-aarch64 --explain

      Compatible with uv.lock, poetry.lock, pdm.lock, Pipfile.lock, pylock.toml, and requirements.txt. Works as a GitHub Action and pre-commit hook. wheelgap on GitHub →

      Each night, wheelgap checks the latest release of top packages from top-pypi-packages against every platform. Pyodide counts only wheels on PyPI; it also ships its own builds of many popular packages.
