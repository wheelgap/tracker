Will your Python project install everywhere?

Paste a GitHub repository. wheelgap reads its lockfile (or its requirements.txt or pyproject.toml), works out the platforms you ship to from your CI and Dockerfiles, and shows every dependency with no prebuilt wheel there (so it's compiled from source, or can't be installed) with the release that fixes it.

      Run the same check locally or in CI:

      It's the wheelgap command line, also a GitHub Action and a pre-commit hook, so a new gap fails the pull request that adds it.

        wheelgap is open source. Run this check in CI with the GitHub Action, or ★ star the project on GitHub.

        Runs in your browser: Python and wheelgap load from jsDelivr and PyPI, the repo's files come straight from GitHub, and release lists from PyPI, which is also asked for each package's files when the repo's file doesn't list them (a requirements.txt or pyproject.toml, say). Nothing goes through a server of ours, and only public repos can be read. The first check downloads about 10 MB, cached after that.
